# Журнал старосты

Личный журнал группы: список, расписание и посещаемость. Без подписки.

Данные остаются в браузере на телефоне. Добавлять людей и ставить отметки можно только с кодом старосты — его задаёте вы при первом таком действии.

Кнопка «Сводка в чат группы» не отправляет сообщение сама. Она копирует текст, кто был и кого не было, чтобы вставить его в чат группы.
